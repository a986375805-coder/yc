`assets/` 保存页面使用的图片，`css/styles.css` 与 `js/main.js` 提供布局、导航及大图交互。页面不依赖远程字体或第三方前端脚本。`js/analytics.js` 向独立采集服务发送匿名访问、项目入口和链接点击事件；不保存原始 IP、姓名或联系方式。访问者可在页脚关闭统计，浏览器隐私信号也会被尊重。统计面板独立登录，访问会话按标签页内 30 分钟活动估算。
